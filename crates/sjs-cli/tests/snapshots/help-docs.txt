sjs docs [entries…] [--format <fmt>] [--out <dir>] [--json] [--quiet]

write reference documentation from doc comments and inferred types  (SPEC.md §13.7)

Flags:
  --format <fmt>  html (default) or md
  --out <dir>     output directory (default docs/)
  --json          print machine-readable diagnostics (the report.json document) on stdout
  --quiet         print only the summary line
  --help          print this text

Exit codes:
  0   no E-code found
  1   at least one E-code
  2   usage error
  70  internal failure
