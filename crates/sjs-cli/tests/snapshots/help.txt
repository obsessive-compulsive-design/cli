sjs <command> [entries…] [flags]

  build   check the program and copy it byte for byte to dist/  (§13.2)
  lint    check the program and print every finding  (§13.3)
  format  print the canonical-layout diff, or apply it with --write  (§13.4)
  test    check the program, then run its tests with coverage  (§13.5)
  map     write the architectural map (modules, dependencies, types, calls)  (§13.6)
  docs    write reference documentation from doc comments and inferred types  (§13.7)
  help    print this list, or a command's flags, defaults and exit codes  (§13.8)
  lsp     serve the Language Server Protocol on stdin/stdout  (§13.9)

Run `sjs help <command>` for its flags, defaults and exit codes; every command also accepts --help.
